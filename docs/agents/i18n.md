# i18n

## Source of truth

Edit these files directly (Nuxt loads them via `nuxt.config` → `i18n.langDir: 'locales'` under `i18n/`):

- `i18n/locales/en.json` — English
- `i18n/locales/de.json` — German
- `i18n/locales/hu.json` — Hungarian

Keep the same nested key shape in all three files. Add or rename keys in **en** first, then copy the branch into **de** and **hu** with translated strings.

## Checks

`utils/i18nLocales.test.ts` asserts key parity and that de/hu are not still English (small allowlist for brands and shared terms like `MyMDb`, `{value}+`).

Run with the rest of the unit tests: `npm test`.

## Error page variants

Meme icons are fixed per variant in `constants/errorScreenContent.ts` (`messageKey` per variant). Matching copy lives under `errors.notFound.<messageKey>` and `errors.server.<messageKey>` in every locale file.
